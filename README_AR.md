# Discord Bots Dashboard V2 — تشغيل محلي

## ما الذي توفره هذه النسخة؟
- تسجيل دخول Discord OAuth2.
- السماح لحساب Discord واحد فقط (ADMIN_DISCORD_ID).
- لوحة واحدة تعرض عدة بوتات، مع زر تشغيل/إيقاف لكل ملف Python.
- واجهة داكنة ومتوافقة مع الهاتف.

## المتطلبات
Python 3.10 أو أحدث، واتصال إنترنت أثناء تسجيل الدخول عبر Discord.

## إعداد Discord OAuth
1. افتح Discord Developer Portal وأنشئ Application.
2. من OAuth2 انسخ Client ID و Client Secret.
3. أضف Redirect URL حرفياً: `http://127.0.0.1:5000/callback`
4. احصل على Discord User ID لحسابك، بعد تفعيل Developer Mode في Discord ثم Copy User ID.

## التشغيل
1. فك ضغط ZIP.
2. انسخ `.env.example` وسمّ النسخة `.env`.
3. املأ القيم في `.env`. أنشئ قيمة عشوائية طويلة لـ FLASK_SECRET_KEY.
4. ثبّت الحزم: `pip install -r requirements.txt`
5. ضع ملفات بوتاتك بصيغة `.py` داخل مجلد `bots`.
6. عدّل `bots.json` لتطابق أسماء الملفات. كل ملف بوت يجب أن يقرأ التوكن من متغير بيئة مناسب.
7. شغّل: `python app.py`
8. افتح `http://127.0.0.1:5000` في نفس الجهاز.

## ملاحظات مهمة
- هذه نسخة محلية؛ لا تجعل التطبيق متاحاً للإنترنت ولا تغيّر `127.0.0.1` إلى `0.0.0.0`.
- تسجيل الدخول يتطلب اتصالاً بالإنترنت، لكن لوحة التحكم نفسها مستضافة على جهازك.
- البوتات لا تعمل إلا إذا كانت ملفاتها موجودة وتبعياتها مثبتة. هذا المشروع لا يصنع ملفات البوتات تلقائياً.
- إيقاف التطبيق الرئيسي قد يترك عمليات البوتات في بعض البيئات؛ أوقف البوتات من اللوحة قبل إغلاقه.
- لا ترفع `.env` إلى GitHub ولا ترسل Client Secret أو Bot Token لأي شخص.
- في Android قد تحتاج Termux وبيئة Python؛ بعض إصدارات أندرويد قد توقف العمليات بالخلفية لتوفير البطارية.
